プライバシーポリシー

アプリ名: メシチカ
制定日: 2026年11月1日

このプライバシーポリシーは、iOS アプリ「メシチカ」（以下「本アプリ」）における、利用者の情報の取り扱いを説明するものです。本アプリの運営者（以下「運営者」）は、個人情報の保護に関する法律そのほかの法令を守り、利用者の情報を取り扱います。

1. 本アプリが集める情報

  • ログインの情報: 「Apple でサインイン」で発行される、利用者ごとの識別子。初めてサインインするときに Apple の画面で名前を共有した場合は、その名前をログインの記録（Firebase Authentication）に保存することがあります。この名前は、ほかの利用者には表示しません（表示されるのは、プロフィールで入力した名前です）。メールアドレスは求めません。
  • プロフィール: 名前（12文字まで）、ひとこと（30文字まで）、プロフィール写真（任意）。
  • 募集・申し込み・チャット: 募集したお店の ID（Apple の地図の Place ID）とジャンル、集合時間、人数、タグ、募集の一言。申し込みの一言と、承認・見送りなどの状態。チャットのメッセージ（「着きました」などの定型の連絡を含みます）と日時。
  • 位置情報（くわしくは「2. 位置情報の取り扱い」）:
    • 端末の現在地（本アプリを使っている間だけ。許可した場合）
    • 募集を作ったときの現在地を約200m単位にぼかしたもの
    • 利用者が地図で決めた「通知を受け取る場所」を約200m単位にぼかしたもの
  • 通知の情報: プッシュ通知を送るための宛先（Firebase Cloud Messaging のトークン）、近くの募集の通知を受け取るかどうかの設定、届いた募集の記録。
  • 安全のための記録: ブロックした相手、通報の相手・理由・日時。
  • 広告に関する情報: 広告を表示するとき、Google の AdMob が端末の情報（IP アドレス、端末の種類、OS など）を取得します。トラッキングを「許可」した場合は、広告識別子（IDFA）も使われます。

本アプリは、連絡先、写真ライブラリの全体（選んだプロフィール写真を除きます）、電話番号、住所、生年月日は集めません。年齢は、18歳以上であることを画面で確認していただくだけで、証明書などは求めません。

2. 位置情報の取り扱い

  • 現在地は、地図に近くのお店や募集を表示するために端末の中で使います。募集を作るときは、現在地をサーバーに送り、約200m単位にぼかしてから保存します。ぼかした位置そのものは、ほかの利用者には見せず、近くの人への通知や表示の範囲の計算に使います。
  • 募集には、ホストのおおよその地域（約5km四方の範囲）を記録し、近くの募集を探すために使います。
  • 集合場所となるお店と集合時間は、本アプリにログインしているほかの利用者が見ることができます。募集を作ると、その時間にそのお店へ行くことが、ほかの利用者に分かることになります。
  • 通知を受け取る場所は、端末で約200m単位にぼかしてから保存します。本人しか読めないように設定しており、ほかの利用者には見せません。ホストには、お店の近くで通知を待っている人の「人数」だけを表示し、誰がどこにいるかは表示しません。
  • 近くの募集を知らせるとき、サーバーは Apple の Apple Maps Server API にお店の ID を送り、お店の座標を一時的に受け取って、通知を受け取る場所との距離を計算します。お店の座標は保存しません（処理のために、サーバーのメモリに短い時間だけ置くことがあります）。
  • 位置情報の利用は、iPhone の「設定」からいつでも止められます。通知を受け取る場所は、本アプリの設定から変えたり、通知をオフにしたりできます。
  • 位置情報を使うかどうか、どこを通知を受け取る場所にするか、どのお店で募集するかは、利用者ご自身で判断してください。位置情報の扱いによって生じた結果について、運営者は責任を負いません。ただし、運営者の故意または過失によって生じた損害は、利用規約の第16条に定める範囲で責任を負います（利用規約の第7条）。

3. ほかの利用者に公開される情報

  • ログインしている利用者全員が見られるもの: 名前、ひとこと、プロフィール写真。募集の内容（お店、ジャンル、集合時間、人数、タグ、募集の一言、ホストの名前など）と、その募集に参加が決まった人とその申し込みの一言。
  • 募集のホストだけが見られるもの: その募集への申し込みと申し込みの一言。
  • ホストと参加が決まった人だけが見られるもの: その募集のチャットのメッセージ。
  • 本人しか見られないもの: 通知を受け取る場所、通知の宛先、届いた募集の記録、ブロックした相手。通報の内容は、通報された相手を含め、ほかの利用者には公開しません。

プッシュ通知の本文には、申し込んだ人の名前と一言、チャットの送り主の名前とメッセージの一部などが入ります。端末のロック画面などに表示されることがあります。

4. 情報の使い道

  • 本アプリの機能（募集、申し込み、承認、チャット、近くの募集の通知、プロフィールの表示など）を提供するため。
  • 近くのお店や募集を表示し、近くで通知を待っている人に募集を知らせるため。
  • ブロックした相手と募集や申し込みでつながらないようにするため。
  • 通報への対応、利用規約に反する利用や不正な利用の防止、利用者の安全を守るため。
  • 広告を表示するため。
  • 不具合の調査、本アプリの改善、お問い合わせへの返答のため。

5. 外部のサービスの利用

本アプリは、次の外部のサービスを使います。それぞれのサービスでの情報の取り扱いは、各社のプライバシーポリシーにもとづきます。

Google LLC

  • Firebase（Authentication、Cloud Firestore、Cloud Storage、Cloud Functions、Cloud Messaging）: ログイン、データの保存、プロフィール写真の保存、サーバーの処理、プッシュ通知。データは主に日本（東京）のサーバーに保存します。
  • AdMob: 広告の表示。トラッキングを許可しなかった場合も、広告は表示されます（利用者に合わせない広告になります）。
  • Google プライバシーポリシー
  • Firebase のプライバシーとセキュリティ
  • Google のサービスを使うサイトやアプリでの Google によるデータの使用

Apple Inc.

  • Apple でサインイン: ログイン。アカウントを削除するときは、本アプリに与えた許可を取り消します。
  • MapKit と Apple Maps Server API: 地図の表示、お店の検索と情報の表示、お店の座標の取得。地図やお店の検索のため、表示している地域や検索の言葉が Apple に送られます。
  • Apple Push Notification service: プッシュ通知の配信。
  • Apple のプライバシーポリシー

Google LLC と Apple Inc. は、米国の事業者です。データは主に日本（東京）のサーバーに保存しますが、各社が米国などのサーバーで情報を扱う場合があります。各社は、それぞれのプライバシーポリシーや契約の条件で、個人情報の保護の取り組みを定めています。米国の個人情報の保護の制度は、個人情報保護委員会のページで確認できます。

6. 第三者への提供

運営者は、次の場合を除き、利用者の個人データを第三者に提供しません。利用者の情報を売ることはありません。

  • 利用者の同意がある場合
  • 法令にもとづく場合（警察などの公的機関から、法令にもとづいて求められた場合を含みます）
  • 人の生命・身体・財産を守るために必要で、本人の同意を得ることが難しい場合
  • 本アプリの運営に必要な範囲で、上の外部のサービスなどに情報の取り扱いを任せる場合
  • 事業の引き継ぎにともなって情報が引き継がれる場合
  • そのほか、法令で認められる場合

なお、「3. ほかの利用者に公開される情報」に書いた情報は、本アプリの仕組みとして、ほかの利用者が見ることができます。

7. 端末から外部に送られる情報

本アプリは、次のとおり、利用者の端末から外部に情報を送ります（電気通信事業法の外部送信の規律にもとづくお知らせを兼ねます）。

  • Firebase（Google LLC）: ログインの識別子、プロフィール、募集・申し込み・チャットの内容、位置情報（上の2のとおり）、プッシュ通知の宛先、端末と通信の情報（IP アドレス、OS など）。本アプリの機能の提供のため。
  • AdMob（Google LLC）: 端末と通信の情報（IP アドレス、端末の種類、OS など）、広告の表示やタップの記録、トラッキングを許可した場合は広告識別子（IDFA）。広告の表示と効果の測定、不正の防止のため。
  • MapKit、Apple Push Notification service（Apple Inc.）: 地図で表示している地域、お店の検索の言葉、通知の宛先など。地図とお店の情報の表示、プッシュ通知の配信のため。

トラッキングの許可は、iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

8. 保存する期間と安全の管理

  • 利用者の情報は、本アプリの提供と、上の使い道のために必要な間、保存します。アカウントを削除したときの扱いは「9. 情報の削除」のとおりです。通報の記録など、不正な利用への対応に必要な情報は、必要な期間、保存します。
  • 運営者は、利用者の情報の漏えいなどを防ぐため、次の対策をとります。
    • 基本の方針: このプライバシーポリシーを定め、法令を守って情報を取り扱います。
    • 組織と人: 情報を扱うのは運営者に限り、運営者が責任を持って管理します。
    • 技術: データベースの読み書きの権限を、本人や必要な処理だけに絞っています（例: 通知を受け取る場所は本人しか読めません）。位置情報はぼかしてから保存します。
    • 物理: 情報はクラウド（Google の Firebase）に保存し、運営者の端末には必要なものしか置きません。
    • 外国の制度の把握: クラウドの事業者（Google LLC）と Apple Inc. は米国の事業者で、データは主に日本（東京）のサーバーに保存します。米国の個人情報の保護の制度を把握したうえで、上の対策をとっています。
  • 安全の管理についてくわしく知りたい場合は、お問い合わせフォームからご連絡ください。安全の管理に支障がない範囲で、遅滞なくお答えします。
  • 運営者は上の対策をとりますが、インターネットを使う以上、完全な安全を保証することはできません。

9. 情報の削除

本アプリの設定（右上の自分のアイコン）から「アカウントを削除」を選ぶと、もう一度 Apple でサインインしたうえで、次の情報を削除し、「Apple でサインイン」の許可も取り消します。削除したものは元に戻せません。

  • ログインのアカウント、プロフィール（名前、ひとこと、プロフィール写真）
  • 申し込み（参加が決まっていた募集からは外れます）
  • 通知を受け取る場所、通知の宛先、届いた募集の記録、ブロックの情報

次の情報は、アカウントの削除後も残ることがあります。

  • ホストした募集（集合前のものは中止になります）と、その募集の記録（ぼかした位置を含みます）。表示される名前は「退会したユーザー」になります。
  • チャットで送ったメッセージ（ほかの参加者の会話の記録として残ります）。
  • 通報の記録（不正な利用への対応のため）。
  • バックアップや、外部のサービス（広告など）が独自に持っている情報。

10. 年齢について

本アプリは18歳以上の方だけが使えます。18歳未満の方の情報を、意図して集めることはありません。18歳未満の方の利用が分かった場合は、そのアカウントを削除することがあります。

11. 開示・訂正・削除などのご請求

ご自身の情報の利用目的の通知、開示、訂正、追加、削除、利用の停止、第三者への提供の停止などをご希望の場合は、お問い合わせフォームからご連絡ください。ご本人であることを確かめたうえで、法令に従って、遅滞なく対応します。法令にもとづいてお応えできない場合は、その旨と理由をお知らせします。

プロフィールの変更とアカウントの削除は、本アプリの中からもできます。

12. 運営者について

本アプリは個人が運営しています。運営者の氏名と住所は、個人情報の保護に関する法律にもとづき、ご本人から求められた場合に、遅滞なくお答えします。お問い合わせフォームからご連絡ください。個人情報の取り扱いについての苦情やご相談も、同じフォームで受け付けます。

13. このポリシーの変更

このポリシーは、法令の変更や本アプリの機能の変更などに合わせて、変更することがあります。変更した場合は、このページでお知らせします。法令で利用者の同意が必要な変更をするときは、本アプリなどで同意をいただきます。
