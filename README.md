# houdoukyokucho.github.io

アプリのサポート・利用規約・プライバシーポリシーをまとめて置く GitHub Pages のサイト。

- `apps/<アプリ>/` にアプリごとのページを置く（今はツミアゲだけ）。
- 恐竜AR（Dino Hunter AR）と線路ラン（Rail Run）は、今は dino-hunter-ar-site にある。あとで `apps/` に移し、App Store Connect の URL を書き換え、古いページは新しい住所へ飛ぶようにする（アプリ内のリンクがあるので、半年ほど残す）。
- 線路ランの app-ads.txt は、このリポジトリの一番上に置く予定。
